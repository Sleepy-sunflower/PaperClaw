# 按规范做一次数据变更

1. 表名和所属用户、创建时间只用 `papers`、`chunks`、`user_id`、`created_at`。
2. 向前迁移只新增表或字段，并写明如何回滚到执行前的表结构。
3. 把新增列的名字、类型和含义写入 `docs/data-dictionary.md`。
4. 新列按密钥、私有、公开三级归类。私有内容不写入日志。
5. 若这次删除文献，同时删掉它的片段和向量，再用同一次检索确认片段不再出现。
